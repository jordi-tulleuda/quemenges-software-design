# Requirement 
### ID: 
RNF-2-05
### Type/Category: 
NO Funcional / Requisits sobre les interfícies externes 
### Version: 
1.0
### Title:
Cercador per introduir el nom d’un plat o cuiner. 
### Description:
A més de poder seleccionar entre els plats/menús o cuiners que mostra l'aplicació, els clients poden també usar un cercador on podran indicar un nom específic de cuiner o el plat que desitgen consumir. Per tant, el sistema ha de proporcionar un cercador per introduir el nom d’un plat o cuiner.
