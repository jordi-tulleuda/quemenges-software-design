# Requirement
### ID:
RNF-1-03
### Type/Category:
NO Funcional / Restriccions de Disseny
### Version:
1.0
### Title:
Longitud mínima del nom d'usuari
### Description:
El sistema ha de garantir que qualsevol nom d'usuari creat tingui una longitud mínima de 5 caràcters. No es permetran noms d'usuari amb menys caràcters.

RF-1-01, RF-1-02
