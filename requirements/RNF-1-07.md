# Requirement

RNF-1-07
### Type/Category:
NO Funcional / Decisions de Disseny
### Version:
1.0
### Title:
Camp opcional de restriccions alimentàries
### Description:
El sistema ha de permetre que els usuaris defineixin de manera opcional les seves restriccions alimentàries (al·lèrgies, menjars no desitjats) dins del seu perfil.
### Relations:
RNF-1-06
### Comments:
Aquesta informació pot ser utilitzada per funcionalitats futures, com la priorització de plats.
